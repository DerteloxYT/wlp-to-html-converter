# WLP to HTML Converter

A simple and clean **Python 3 script** that converts **WLP (Web Language Program)** files into fully functional HTML pages.

---

## 🚀 Features

- Converts `textbox`, `inputtext`, and `button` elements  
- Supports `onclick` JavaScript events  
- Handles `head` properties: `title`, `wlp-pro-key`, `background-color`, `text-color`  
- Outputs clean HTML ready to open in any browser  

---
